# Security model and disclosure

This is an offline static REVIEW AID, not a security scanner guarantee. Inputs may be sensitive; never upload production plans/manifests or paste report details into public issues. Do not run with elevated privileges. The tool does not write to the audited infrastructure and makes no network requests. For a suspected vulnerability in the tool itself, open a private GitHub security advisory in this repository rather than sharing exploit material publicly. No response-time SLA is promised.
